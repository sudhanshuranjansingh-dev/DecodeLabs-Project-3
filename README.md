# 📊 Data Analytics Project – Part 3

## 📌 Project Overview

This project is the third part of my Data Analytics internship. The objective was to clean, organize, and analyze a sales dataset using Microsoft Excel and MySQL to gain meaningful business insights.

---

## 🎯 Objectives

* Clean and prepare the dataset.
* Analyze sales and order information.
* Perform SQL queries for business analysis.
* Extract useful insights from the data.

---

## 🛠️ Tools & Technologies

* Microsoft Excel
* MySQL
* Git & GitHub

---

## 📂 Dataset

The dataset includes:

* Order ID
* Order Date
* Customer ID
* Product
* Quantity
* Unit Price
* Total Price
* Payment Method
* Order Status
* Shipping Address
* Referral Source

---

## 🧹 Data Cleaning

The following data cleaning tasks were performed:

* Corrected date formats
* Removed duplicate records
* Checked for missing values
* Corrected inconsistent data
* Verified data types

---

## 📊 SQL Analysis

The following analyses were performed:

Display all orders.
Display only delivered orders.
Find all Laptop orders.
Sort orders by TotalPrice (highest to lowest).
Count the total number of orders.
Count orders for each product.
Calculate total sales.
Calculate average order value.
Find the highest-priced order.
Find the lowest-priced order.
Find total quantity sold for each product.
Show products with more than 100 units sold (HAVING).
Count orders by payment method.
Count orders by referral source.
Find total sales for each order status.
